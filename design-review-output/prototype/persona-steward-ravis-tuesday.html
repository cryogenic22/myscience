incoming field · oversightHasDmc: boolean · 8 trials · all true
existing field · data_monitoring_committee_present: boolean · same semantics, currently NULL on the 8 trials
match score · 0.97 (Curator semantic match)
precedent · CT.gov has renamed similar fields 3 times in past 18 months · we mapped each cleanly
Curator recommended
Map to existing field · backfill 8 trials
No schema change. Backfill data_monitoring_committee_present = true for the 8 affected trials. Add an alias rule so future oversightHasDmc values land in the existing column. Done in 4 minutes.
Alternative
Extend schema · add new column
Adds clinical_trials.oversight_has_dmc as a new boolean. Keeps both fields. Requires a migration, downstream view updates, a deprecation plan for the old field. Avoid unless we know they diverge.
