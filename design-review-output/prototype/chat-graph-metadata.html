Surface 3 · Progressive metadata disclosure
Six patterns. One disclosure hierarchy. Applied everywhere.

Today, metadata is scattered — citations clickable but unreliable, confidence on the canvas but not in chat, evidence as opaque IDs, three different trust vocabularies on the same screen. The pattern library below fixes that. Every metadata artefact follows the same four-level disclosure: glance (always visible, sub-half-second), hover (250ms, brief preview), click (full detail in side panel), drawer (everything connected to it).

Pattern 1 · the most-used artefact
Citation chip
Inline numbered reference. Carries source tier in its colour, opens to a passage on click, opens the full evidence drawer on shift-click. The atom of trust in every answer.
The FDA Complete Response Letter1▸ created a 60-90 day window2▸ in which our Q3 launch can either pre-empt Pfizer or be pre-empted3▸. Posterior shifted +8 points4▸ after KEYNOTE-869.
Glance: green (T1), blue (T2), violet (T3) tells you the source quality without reading.
Hover shows source name + date + 1-line snippet.
Click opens the matching evidence card in the right panel · highlights it.
Shift-click opens full source document in literature explorer.
Pattern 2 · entity in prose
Entity badge
Inline-coloured + dashed underline. Type encoded in colour (drug=blue, company=amber, trial=teal, mechanism=violet). Pivots the working set on click; opens dossier on shift-click.
tirzepatide is Eli Lilly's lead asset in the GIP/GLP-1 mechanism class. Comparable assets from Pfizer (amivantamab) are tested in KEYNOTE-869.
Glance: colour tells you what type of thing it is.
Hover shows entity card with status + last-touched + connection count.
Click adds entity to working set + pins it.
Shift-click opens full dossier in a new pane.
Pattern 3 · trust in one glance
Confidence pill (multidimensional)
Single number plus four dimension bars. Replaces the three-vocabulary mess of confidence + impact + materiality with one composite + factor breakdown. Always visible on every assistant turn and every recommendation.

Today the chat answers, the graph renders, and the metadata is present. None of the three is yet a tool you can think with.
The fix is structural, not cosmetic. Wire the conversation memory that's already coded so each turn carries the entity context of every prior turn. Pivot the graph from a picture into an interlocutor by giving it an "ask this subgraph" panel. Apply one disclosure pattern (glance · hover · click · drawer) to every metadata artefact across both surfaces. Three changes; the product becomes a thinking partner instead of a Q&A interface.
