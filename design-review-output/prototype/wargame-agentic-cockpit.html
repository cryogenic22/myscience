The authority spectrum
Five levels of agent autonomy. Bounded, calibrated, auditable.

Not every decision needs a human. And not every decision should be made by an agent. The five-level spectrum below is how the platform maps decision authority — from level 1 (agents observe only, humans decide everything) to level 5 (agents decide and act, humans audit retrospectively). Each scenario type has a default level the team can change. Authority can be earned (an agent that calibrates well over time can be promoted) or revoked.

L1
Watch only
Human · 100%
Agents observe and surface. Humans decide everything. Default for first-time scenarios, novel TAs, or whenever calibration is unknown.
Example: a new adversary twin (just-onboarded competitor) — the system shows you the modelled posterior but does not run scenarios against it without your approval.
L2
Suggest
Human · 95%
Agents run analyses and propose findings. Humans review every output before it shapes a decision. Default for high-stakes financial impact (>$50M).
Example: "should we accelerate Q3 launch" — agents do the war-game, you decide every time. The agents' work is input, not output.
L3
Recommend
Human approves · 80%
Agents have done the analysis, made the call, and pre-drafted the brief. Humans approve, edit, or reject. Default once an agent's calibration on a scenario type exceeds 0.70.
Example: "weekly stress-test of Q3 plan against new Pfizer evidence" — Strategist auto-runs every Monday, drafts the changes, you approve the diff in 2 minutes.
L4
Act with notice
Agent · with audit
Agents act within bounded authority. Humans are notified after the fact. Default for low-stakes or reversible actions (parameter tuning, scenario re-runs, posterior updates).
Example: "update Pfizer posterior when new evidence arrives" — Curator updates without asking; you see the diff in the morning.
L5
Auto · audit-only
Agent · 100%
Agents act fully autonomously. Humans audit retrospectively. Default for housekeeping (rerunning stale scenarios, recomputing source weights, archiving stale twins).
Example: "rerun any scenario whose underlying evidence has shifted >10% in 30 days" — runs automatically, surfaces only if findings change materially.
How authority is earned (or revoked)
Curator runs a calibration window per agent per scenario type
Strategist on "Q3 launch under regulatory uncertainty" has run 14 scenarios over 90 days, calibration 0.78 — eligible for L3 (recommend). Strategist on "M&A scenario in TA we don't track" has 0 calibration data — locked to L1 (watch only). When calibration drops, the agent is auto-demoted; when it rises, you're invited to promote.
Delegation · "run while I sleep"
Queue a scenario in the morning. Read the verdict at 7am.

Some scenarios are too expensive to run in real time (full sensitivity sweeps, deep counterfactuals, multi-twin sensitivity). You queue them with parameters; agents run overnight; findings land in your morning Pulse. The verdict is auditable end-to-end — every iteration is logged, every assumption is preserved, every cell of every payoff matrix is replayable.

The argument in one paragraph
War-gaming is too important to be a meeting. The agents will simulate continuously whether you watch or not. The question is whether the platform makes their work visible, calibrated, contestable, and bounded — or whether it lets them run silently and hands you a summary you can't interrogate.
The cockpit is the answer to that question. Agents do the work; humans do the judgement; the authority spectrum decides who acts. Every output is grounded, every iteration is replayable, every calibration is visible. The future workforce scales the same model — more agents, more twins, more scenarios, same trust spine.
