5 · Engineering posture

  • Real-DB gated. Every loop with backend impact was red-teamed against the live Railway DB on the semaglutide engagement — not mocks. This caught real issues (the all-scenarios-blocked dead-end, a self-referential competitor, recall-noise concentration).
  • Additive prod writes only. Migrations 072–076 are additive + idempotent (IF NOT EXISTS); the facts ledger is append-only; no destructive cleanup ran. Throwaway red-team rows were cleaned up.
  • Reuse-first. One container pattern (loading → not-derived → ready → error) reused across all 7 stages; ProvenancePanel and EntityComments are shared primitives, not per-stage copies.
  • No fabrication. NPV was left blank rather than invent bn-DKK figures; the brief shows an honest empty state where no BCB exists; impact vectors are labelled “structural estimate, not a forecast.”
  • Verification gate per loop: vitest run (906 passing) + tsc --noEmit + vite build, plus the relevant Python suites.

6 · Honest gaps & what they need

  • ◆ NPV value model (PB-H10 remaining). Decision options carry no NPV. Needs a defensible model (PharmaMetrics-driven or analyst-supplied) before showing figures.
  • ◆ In-app brief editing (PB-UX08 remaining). The brief is read + discussable; authoring/editing it outside the create flow needs a PUT endpoint + form.
  • ◆ Demo brief is empty. The semaglutide engagement has no BCB authored, so the brief stage shows the empty state — author one via the create flow for a full demo.
  • ◈ Learn loop (PB-H14). Scenario priors are structural heuristics; they don't yet re-calibrate from outcomes. Needs the signal→scenario link (PB-H01).
  • ◇ Data breadth (Epic E17). All sources are public today; licensed/internal/contributed tiers + transcript ingestion are the deferred data-hub track.

7 · Recommended next

  1. Author a BCB for the demo engagement so the brief stage shows real content (5-minute content task, not code).
  2. Learn loop (PB-H01 → H14) — the highest-leverage intelligence gap: make scenario probabilities move as signals arrive.
  3. Data Hub Phase 0 (E17 / PB-D01–D03) — activate the dormant document upload, register the quality-monitor hook, populate the evidence ledger on ingest. “80% of the value for 20% of effort.”
  4. NPV value model — only once there's a defensible basis; until then the structural impact vectors carry the war-gaming depth.
