1 · The architecture in one picture

The thesis the whole system is built on: one knowledge store; everything else is a lens over it. A signal, a dossier domain, a KBQ view, a scenario prior — none is a separate store; each is a scored, timed, routed view of the same facts ledger. Data of any kind (public API, licensed feed, uploaded PDF, meeting transcript) enters through one spine; the difference between source tiers is how data enters, not how it flows.

┌─ SOURCES ────────────────────────────────────────────────────────────┐ Tier 1 PUBLIC (live: FDA · ClinicalTrials · PubMed · SEC · EMA · ChEMBL · NADAC · News …) Tier 2 LICENSED · Tier 3 INTERNAL · Tier 4 CONTRIBUTED · Tier 5 LEARNED (aperture to widen) └───────────────────────────────────┬───────────────────────────────────┘ ↓ ┌─ INTEGRATION SPINE (5 stages + 7 hooks) ───────────────────────────────┐ FETCH → NORMALISE → RESOLVE (6-strategy cascade) → EMBED → STORE → CROSS-LINK ValidationGate · ChangeDetection · QualityGate · NewEntityReview · Staleness … DLQ └───────────────────────────────────┬───────────────────────────────────┘ ↓ ┌─ KNOWLEDGE MODEL (the agentic-ready substrate) ─────────────────────────┐ Entities · Facts (temporal · fact_class · provenance) · Evidence ledger · Graph · Embeddings └───────────────────────────────────┬───────────────────────────────────┘ ↓ (lenses — not stores) SENSE (signal = scored fact) → FRAME → SIMULATE/WAR-GAME → DECIDE → LEARN └── Dossier (8 domains) · KBQ views · Scenario priors · Chat/synthesis · War-room

The flywheel goal: compress signal→decision latency from 4–12 weeks to <24h for high-materiality signals, and self-calibrate over time. The load-bearing invariant is a validated provenance graph — signal → fact → insight → scenario → decision → outcome, every edge resolvable, nothing asserted without a source.

3 · What has been achieved

The substrate is real and production-grade — and three conversion joints were unblocked this cycle.

The hard part (a genuine knowledge model with entity resolution, an append-only temporal fact ledger, content-addressed evidence, a typed entity graph, embeddings, and FAIR quality scoring) exists and runs. This cycle moved the system from "ingest-rich but conversion-dead" toward "ingest-rich and converting."

  • Honest fact-class trust grading (PR #279, prod-applied). 79.8% of facts sat in a corporate catch-all that was 98.8% authoritative registry/regulatory data (not news). Now classified by source: reference 3,160→14,092; the lens can finally tell a CT.gov readout from a press release.
  • Pricing now reaches the ledger (PR #280, prod-applied). 290 landed NADAC rows that never became facts now bridge to net_price facts, honestly labelled as Medicaid acquisition cost (not WAC).
  • Sensing turned on (PR #283, prod-applied). The conversion step (events+facts→signals) ran on no cadence — signals were 11 days stale. Now scheduled (6-hourly), filtered to high-significance events: feed fresh to today, signal↔fact provenance links 66→313, 50 high-value signals shipped, recall noise retracted. This is the first edge of the provenance graph going live.
  • Signal→entity resolution un-capped (prod-applied this session). The promoter and backfill resolved headlines against only ~18 curated entities, so the backfill resolved zero. Now the gazetteer spans the full company/drug universe at a precision-safe floor (full canonical names + hand-vetted aliases). A read-before-write prod probe caught — and hardened away — junk-row mis-matches (drug classes, trial arms, generic-word companies) before mutating; the reversible backfill then moved the 'market' bucket 747→701, every relink precision-verified. The second provenance edge (signal→entity) is now wired.
  • Conservation discipline held throughout. Every prod mutation was idempotent + reversible + counted; every change RED→GREEN tested and independently reviewed; no protected gate edited to pass.
  • The full pipeline was prod-audited end-to-end (corporate/pricing/news → schema → linkage → sensing), separating stale doc claims from real gaps against live data.

5 · Assessment

5.1 · Best-in-class & value vs the market

The honest one-liner: architecturally best-in-class for a knowledge model; operationally maturing; data-breadth behind the licensed incumbents. Most pharma-CI tools (IQVIA, Evaluate, Citeline, Cortellis, Datamonitor) win on licensed data breadth and go straight from API → dashboard → slide. Market Zero is the rare one that puts a real knowledge model + provenance graph underneath — that is the moat.

Architecture rigor

A‑ — strong, with discipline

  • Separation of concerns is real: connectors ⟂ pipeline ⟂ knowledge model ⟂ lenses.
  • Conservation gates (append-only ledger, no-silent-loss, RED→GREEN, two-lane CI, protected-surface + CODEOWNERS) are a genuine engineering floor most teams skip.
  • "Lens, not store" is a disciplined invariant — signals/dossier/KBQ/scenarios all derive from one ledger.
  • Honest deduction: two divergent post-task runners + inert hooks show some accretion — rigor is high but not perfect.
Modularity

A — genuinely pluggable

  • BaseConnector (fetch + health + source_type) — adding a source = one class.
  • FactEmitter framework — entity-table→facts in one pure row_to_facts; 10 emitters, all idempotent.
  • Generic config-driven connectors (CSV/RSS/REST) — onboard without code.
  • Predicate/fact_class taxonomies as single sources of truth; declarative cross-link rules.
  • One caveat: a new predicate must register in 4 routing maps or it silently degrades — modular but with a coupling tax.

The bottom line.

Market Zero's bet — the data layer is the product — is sound and largely built. The knowledge model, provenance ledger, entity graph, and conservation discipline are best-in-class for the category and are the durable moat; few CI tools have anything like them. The honest gaps are (1) the provenance spine's second edge (signal→entity), now next; (2) the decide/war-game vertebra, the highest-value frontier; and (3) data breadth beyond public sources. None is an architecture problem — they are activation, connection, and aperture. The system is closer to its vision than it looks, and every fix compounds because everything is a lens over one store.
