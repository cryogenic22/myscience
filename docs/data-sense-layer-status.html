Why the gaps happen (verified)

  • market_events: the event collector resolves primary_entity_id only when a generic/brand name is confidently matched; news/SEC text rarely contains a clean drug mention, so 99.6% stay NULL. Compounded by massive duplication — the top dup group is 1,041 copies of one event. Read-time dedup hides this in the UI but the ledger ingests the noise (3,301 market_event facts = 33% of the whole ledger). [db + code: services/event_collector.py]
  • pubmed: the EVIDENCE_FOR link only fires when the article's generic_name resolves; MeSH-only articles (no drug string) don't link. [code: cross_linker + pack.py]
  • bioactivities: drug_id is NULLABLE and there is no link rule at all in domain/pharma/pack.py — orphaned by design. The BioactivityEmitter JOINs on drug_id → 0 rows → emits 0 facts. [code: fact_emitters/mechanisms.py]
  • resolution debt is growing: unresolved_entities 46,579 (↑ from 46,318), hitl_review_queue 29,429 (↑ from 28,754), steward stuck at 263 — nothing drains them. [db]
