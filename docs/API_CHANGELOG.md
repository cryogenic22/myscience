# API Changelog

Append-only log of every backend API change. **Claude writes; Antigravity reads
at the start of every session.**

Format per entry: `## YYYY-MM-DD` then sections `### Added`, `### Changed`,
`### Deprecated`, `### Removed`, `### Migration notes for frontend`. Omit
empty sections.

Snapshot of the live OpenAPI spec lives at `schema/openapi.json` and is
regenerated by `python -m scripts.snapshot_openapi`.

---

## 2026-05-09

### Added
- **AGENTS.md protocol adopted.** All API changes from this date forward will
  be logged here. The OpenAPI snapshot at `schema/openapi.json` is now the
  single source of truth between backend and frontend.

### Migration notes for frontend
- None for this entry — purely a process change.
- For a complete picture of what's currently live, regenerate the OpenAPI
  snapshot (`python -m scripts.snapshot_openapi`) and inspect
  `schema/openapi.json`.
