What's left — and the key missing loops

The one that matters most: the Learn loop doesn't close. The flywheel is sense → decide → act → learn. Correction after code-review (the machinery is more built than first stated): outcome detection is wired and runs hourly (outcome_scheduler registered in api/app.py), and the calibration primitives exist (learning_service.ewma_update, outcome_detector, calibration_math, feedback_loops). But it's effectively dormant — there are no committed decisions with observed outcomes yet to learn from (EWMA runs = 0) — and the two pieces that actually matter are unbuilt: (1) scenario-prior recalibration — the scenarios.current_prob / calibration_note columns exist but nothing writes them from arriving signals (PB-H14); (2) feed re-ordering from calibration (PB-IX06). So: the wiring is there, the loop is open. Highest-leverage gap once there's rich data + outcomes to learn from.

Part B · Data & sense-layer richness

The diagnosis — measured, not guessed

You're right that the data feels thin. But the cause is surprising: it isn't that we lack sources — it's that the rich structured data we already ingest never reaches the dossier as evidenced, domain-typed facts. (Verified against the live DB + the dossier read-path code.)

The smoking gun (live DB, 2 Jun): the facts ledger — what every dossier, synthesis and scenario is built from — has 3,303 rows but only 2 distinct predicates: market_event (3,302) and wac_usd (1). Meanwhile, sitting in entity tables, untouched by the ledger:

Precision after code-review (the first draft over-simplified this). The dossier is not purely the facts ledger — assemble_dossier blends four feeds: the ledger (event facts) + compose_dossier recent signals + the competitive graph (related entities) + PharmaMetrics aggregate metric facts (e.g. "trial success rate 95%", "187 PubMed articles"). So it isn't barren — competitive and aggregate-clinical do get real content. But the granular structured data — individual trial readouts/endpoints, specific safety signals, label indications, real prices — reaches none of those four paths as domain facts. So the dossier has aggregate metrics without the underlying evidence: pricing/access shows a critical gap on a single WAC fact, safety has no FAERS-derived facts, and scenarios lean on the competitive graph + news rather than trial- and label-level evidence. The facts ledger specifically is the monoculture (2 predicates); the fix is to make the rich structured sources emit into it.

The good news: this is a plumbing problem, not a sourcing problem. The connectors work, the data is in the building, the predicate→domain router already exists (route_predicate_to_domain), and the evidence-ledger schema is built. We need a thin fact-emitter layer that turns entity-table rows into domain facts (with evidence) — no new data sources required.

The plan — make the sense layer rich from what we already have

A sequenced track (DR-loops) that lifts latent data into the ledger, writes evidence as it goes, and keeps it fresh. Same loop discipline: TDD + real-DB red-team + additive prod writes.

What this unlocks

  • The dossier fills out. Pricing/access, clinical, safety and disease domains go from "gap" to evidenced — readiness climbs from ~36% toward the level a brand team would trust.
  • Scenarios get sharper. Grounded in trial readouts, safety signals and real prices — not just news + the competitive graph.
  • Provenance becomes real. Every fact carries an evidence record; the drill-through stops being mostly empty.
  • It compounds with the Learn loop. More, better-typed facts give calibration something to learn from.

Note: the genuinely licensed gaps (IQVIA/Rx volume, claims, real prescriber behaviour) remain — they're the HCP-adoption + commercial-share domains that public data can only partly proxy. Those stay in the deferred Data Hub (E17, tiers 2–3). DR-1..8 is everything achievable from free sources we already pay nothing for.

Recommended priority across both tracks

  1. DR-0 + DR-1 + DR-2 — fact-emitter framework + clinical + pricing. Biggest, fastest dossier-quality jump from data we already hold.
  2. DR-5 — evidence-on-ingest, so the new facts are traceable from day one.
  3. PB-IX01 promote bridge — connect Sense → work (the IA's missing link).
  4. PB-H14 / IX-6 Learn loop — close the flywheel once there's rich data to learn from.
  5. DR-3/4/6/7/8 — broaden coverage + keep it fresh.
