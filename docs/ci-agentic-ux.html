Competitive Intelligence — Agentic UX

Backlog PB-1302 Date 2026-05-22 For Kapil · Amit · Riya Status draft for review

Today's /ci is a BI dashboard: a feed of signals + manual buttons where the human is the engine. The agentic future inverts it — agents sense, frame, simulate and recommend; the human steers and judges. The unit of work stops being a signal to read and becomes a decision the system has already framed and war-gamed. This doc specifies that workflow, the three agents' surfaces, and the war-game mode toggle (autonomous · hybrid workshop · game-theory substrate).

The shift in one line

From "read 569 signals → decide what matters → manually frame" to "the system surfaced 3 material Moments with framed options and simulated outcomes → I interrogate, adjust assumptions, and commit — with full trace."

1Why today feels old-school

Old-school (today)

  • Land on a feed of 569 signals
  • Human reads, decides relevance
  • "Frame" / "Simulate" are blank manual buttons
  • Agents are static labels in the sidebar
  • War-game = a form you fill from scratch
  • No memory, no learning, no proactivity

Agentic (target)

  • Land on 3–5 Moments the agents framed
  • Agents pre-rank by materiality & EV-at-stake
  • Options + war-game already drafted
  • Agents are colleagues with live activity + trace
  • War-game = a dialogue you steer
  • Curator closes the loop; calibration improves

2The agentic model

Three principles, each a concrete UX rule:

  1. Decisions, not data. The home surface is Moments (framed decisions), not a signal feed. The feed becomes the evidence substrate underneath.
  2. Agents propose, humans dispose. Every Moment arrives with agent-drafted options + a pre-run war-game + a recommendation. The human's job is judgment, assumption-adjustment, and commitment — never blank-page work.
  3. Conversational, with trace. The user steers in natural language ("re-run assuming Novo cuts WAC 50%"); every agent action is inspectable end-to-end (which signals → which belief shift → which option → why).

4The three agents & their surfaces

Sentinel — Sense

Clusters raw signals into Moments; scores materiality; detects belief shifts. Surface: the Bridge Moments column (exists at /bridge). Live activity in the cockpit rail (exists — /agents/activity).

Agentic upgrade: proactive — pushes "a Moment crossed your materiality threshold" rather than waiting to be read.

Strategist — Frame + Simulate

Turns a Moment into a framed Decision Brief and pre-runs the war-game. Surface: the Decision Workspace (exists, 5-panel) made conversational. Drafts options with cited evidence; proposes adversary panel.

Agentic upgrade: the workspace gains a chat rail — the user interrogates and re-simulates in natural language.

Curator — Learn + Recalibrate

At each decision's review date, compares predicted vs actual; recalibrates materiality weights. Surface: Insights (exists) made live.

Agentic upgrade: close the loop — outcome attribution feeds back into Sentinel's scoring.

5War-game — the mode toggle

The war-game engine exposes one toggle, three modes (product-owner requirement). Game theory is the computational substrate underneath, not a separate mode the user thinks about.

ModeWho plays the adversariesHuman roleOutput
① AutonomousAI agents (competitor/payer/FDA/KOL), grounded in the knowledge graphReviews the agents' self-analysis + recommendation; takes the decision where flaggedRecommendation + full reasoning trace (every move, every assumption)
② Hybrid workshopMixed — a human may take an adversary seat (e.g. "play Lilly"); AI plays the restActive participant in a live red-team roomTranscript + group decision; richer for facilitated sessions
③ Game-theoryFormal payoff matrix; Monte-Carlo / Bayesian (services/game_theory.py)Sets payoffs / priors; reads equilibria + EV distributionsQuantified equilibrium + EV ranges — the math layer feeding ① and ②
Design intent (from product owner)

"A toggle where the engine allows for 1/2/3. Ideally the agents do self-analysis and report back, with humans taking decisions where needed and a full trace — or a workshop-oriented human/AI team, with game theory as a subset within mode 2 using those mechanisms."

Adversaries are grounded. Each adversary agent is seeded with the entity's real profile from the knowledge graph (trials, pricing, history, prior moves) + an objective function. That's the data moat doing the work — not a generic LLM persona.

6Surfaces & contracts

Primary (hero) — make these excellent

  • Bridge / Moments (/bridge) — the home. Moment cards → open into the decision flow.
  • Decision Workspace — agent-drafted brief + conversational war-game (the new chat rail) + mode toggle.
  • War Room — the live multi-agent simulation surface (modes ①/②/③).

Evidence layer (quiet) — consistent, not hero

  • Signals DB, Sensing Feed, Watchlist, Reviewer — the substrate. Already Helix-reskinned; keep quiet.

Key new contract — the conversational war-game

POST /wargame/{session_id}/steer
  { "instruction": "re-run assuming Novo cuts WAC 50% in Q1 2027",
    "mode": "autonomous" | "hybrid" | "game_theory" }
→ { "rounds": [...], "ev_by_option": {...}, "belief_delta": {...},
    "trace": [ {agent, input, reasoning, output}, ... ] }   // full trace
